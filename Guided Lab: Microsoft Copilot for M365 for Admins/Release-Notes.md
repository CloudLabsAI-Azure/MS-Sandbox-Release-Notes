### Content Changes

- **Lab Modules / Exercises**: Removed "Understanding Semantic Index for M365 Copilot" and "Managing Microsoft 365 Copilot Licenses in Admin Center" as standalone modules, neither exists in the admin masterdoc; license verification is a task inside the Administering M365 Copilot exercise, not a separate module. Corrected the list to the actual four top-level exercises: Introduction to Microsoft Copilot for Microsoft 365; Understanding M365 Copilot Architecture; Administering M365 Copilot; Reviewing Security and Compliance in Copilot.
- **Course Overview**: Rewrote to remove the Semantic Index reference and instead cover the Microsoft 365 Admin Center and Microsoft 365 Apps Admin Center (license/service verification, web content access, update channels), and the Microsoft Purview compliance tools actually used (sensitivity labels, Customer Key, communication compliance, audit, content search, eDiscovery, retention policies).
- **Featured Product**: Replaced generic tags ("Administration", "Governance", "Tenant Configuration", "User Management") with the specific products used: Microsoft 365 Admin Center, Microsoft 365 Apps Admin Center, Microsoft Purview, Microsoft Graph, Microsoft Entra ID, Sensitivity Labels, Customer Key, Communication Compliance, Audit, eDiscovery, Retention Policies.
