## Release Date: 2026-11-24

### Summary of Changes

Updated the resource creation steps across the lab guide to match the latest Azure portal experience. The Marketplace result cards no longer show a **Create** option, so learners now open each service from the portal search bar and select **+ Create**. Added guidance for the new Create-VM preview experience and the Microsoft Edge first-run screens. Validations were reconfigured and a new validation was added for the virtual machine deployment.

### Infrastructure Changes

N/A

### Content Changes

- In Lab 01 (Building a Virtual Network), Lab 02 (Create an Azure Availability Set) and Lab 03 (Deploy a Virtual Machine), the creation flow through **+ Create a resource** and Marketplace has been replaced. Learners now search for the service (**Virtual networks**, **Availability sets**, **Virtual machines**) in the portal search bar and select **+ Create**.

- In Lab 03 (Deploy a Virtual Machine), retained the note on switching from the Create-VM preview experience to the previous experience, so that the **Availability set** option is available under **Availability options**.

- In Lab 03 (Deploy a Virtual Machine), added a validation step for the virtual machine deployment.

- In Lab 04, added the **Region** field to the **Enable backup** step, and renumbered the callouts to match the updated screenshot.

- In Lab 06, added a note to skip the Microsoft Edge first-run setup screens (**Continue without this data**, **Skip** or **Not now**) on **DEMOLABVM01**.

- Updated validation step IDs in Labs 01, 02, 04, 05 and 06.

### Screenshot Updates

- Added new screenshots for the search-and-create flow in Labs 01, 02 and 03.

- Updated the **Enable backup** screenshot in Lab 04 to reflect the latest UI.

### Testing Scope
