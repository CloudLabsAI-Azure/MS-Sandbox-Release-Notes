## Release Date: 2026-09-16

### Summary of Changes

Performed end-to-end lab testing and validations, with major content updates.

### Infrastructure Changes

N/A

### Content Changes

- The lab has been updated to use the **new Microsoft Copilot Studio experience**, and all instructions now guide learners to build, test, and publish their agent within that experience.
- The agent build flow has been aligned to the new experience, covering agent creation, knowledge, skills, workflow-based ticket creation, and publishing to Microsoft Teams.
- A parallel **high-level** version of the guide has been introduced alongside the existing step-by-step guide, allowing the lab to be delivered at either altitude.
- In the high-level version, instructions were rewritten to be **goal-oriented**: each task now leads with the outcome the learner must achieve and the exact values their work must use, while navigation and click-by-click direction has been removed so learners determine the approach themselves.
- All resource names, configuration values, and success criteria were preserved across both versions, so either version produces the same end result.
- Agent instructions and skill descriptions were refined to ensure the agent reliably follows the intended troubleshooting paths, and test prompts were updated to match.
- The guide has also been updated to align with the latest Copilot Studio UI for improved clarity and accuracy.
