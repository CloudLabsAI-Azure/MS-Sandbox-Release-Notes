### Summary of Changes

## Content Changes

- Updated the Azure Databricks labs to work with **Unity Catalog**, which new workspaces now use by default with the **DBFS root** and **hive_metastore** turned off.
- **Lab 1 – Explore Azure Databricks:** Removed the DeploymentID-based resource group and workspace names, which the setup script generates with a random suffix. Clarified the steps to download **products.csv**, updated the **Copy URL/path > Full path** step for the current workspace UI, and updated the sign-in step to use the **Temporary Access Pass**.
- **Lab 2 – Analyze files in Azure Databricks:** Updated the notebook to download the data files into a **Unity Catalog volume** instead of DBFS. Updated the lab guide with the import, ingest, query, Spark SQL, and visualization steps, and added new screenshots.
- **Lab 3 – Delta Lake in Azure Databricks:** Updated the notebook to store Delta files in a **Unity Catalog volume** and create **managed tables** in the workspace catalog. Updated the update and verify cells to display product **771** directly, so the updated price is visible. Added a note to rerun the first cell if the cluster restarts, and added new screenshots.
- **Lab 4 – Azure Databricks SQL:** Replaced **hive_metastore** with the workspace catalog (**databricksxxxxxxx**). Aligned the steps with the current **SQL editor** (Run all) and **dashboard** experience, and added new screenshots.
- **Lab 5 – Azure Databricks with Azure Data Factory:** Updated the notebook to save output to a **Unity Catalog volume** instead of DBFS. Updated the **access token** steps for the new token dialog, where the **Auto-scope tokens** option replaces manual API scope selection. Updated the expected pipeline output path, and added new screenshots.
- Added notes on the resource group and workspace name suffix generated by the setup script, and on cluster reuse with **Databricks Runtime 17.3 LTS**.
- Fixed typos, headings, list formatting, and the lab summaries.
